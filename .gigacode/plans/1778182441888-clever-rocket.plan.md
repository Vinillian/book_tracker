# План локализации интерфейса приложения Book Planner

## Цель
Перевести строки интерфейса в указанных Dart-файлах с английского на русский язык в соответствии с предоставленными таблицами соответствий.

## Затрагиваемые файлы
- `lib/screens/editor_screen.dart`
- `lib/screens/notes_screen.dart`
- `lib/screens/item_card_screen.dart`
- `lib/screens/planner_tab_view.dart`
- `lib/screens/home_screen.dart`
- `lib/screens/backup_restore_screen.dart`
- `lib/widgets/book_card.dart`

## Этапы реализации

### 1. Анализ и подготовка
- Подтвердить наличие всех целевых файлов в проекте с помощью `find_files`.
- Прочитать содержимое каждого файла, чтобы:
  - Убедиться в точном соответствии строк для замены.
  - Учесть контекст (например, экранирование кавычек, использование интерполяции строк).
  - Выявить строки, встречающиеся несколько раз (например, 'Delete', 'Cancel'), и определить, нужно ли заменять все вхождения (`replace_all: true`) или только уникальные.

### 2. Поэтапная замена строк
Для каждого файла:
1. **Прочитать** файл.
2. **Выполнить** все замены с помощью `edit_file`, используя `replace_all: true` для неуникальных строк.
3. **Проверить** результат, при необходимости внося корректировки.

Особое внимание:
- В `notes_screen.dart` строка `'Delete'` встречается дважды, поэтому для её замены требуется `replace_all: true`.
- В `editor_screen.dart` строка `'Cancel'` также встречается несколько раз.

### 3. Верификация
- Запустить приложение (`flutter run`) для визуальной проверки корректности перевода.
- Убедиться, что интерфейс отображается на русском языке без битых строк или ошибок верстки.

## Критические файлы
- `lib/screens/editor_screen.dart`: основной экран редактирования элементов.
- `lib/screens/notes_screen.dart`: экран управления заметками.

## Проверка
После всех изменений:
1. Запустить приложение на устройстве или эмуляторе.
2. Перейти на экраны `Editor`, `Notes`, `Home`, `Backup & Restore` и убедиться, что все элементы переведены.
3. Проверить работу диалогов (удаление, сохранение) на корректность отображения текста.

План составлен. Готов перейти к реализации после подтверждения.
