# Security Policy

## Supported Versions

The following versions of Book Planner are currently receiving security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a vulnerability in Book Planner, please report it responsibly.

### How to Report

Send an email to **ber07@inbox.ru** with the subject **"Security Vulnerability – Book Planner"**.
Please include:

- The version of the app where the issue was found
- A detailed description of the vulnerability
- Steps to reproduce (if available)
- Potential impact of the issue

### What to Expect

- You will receive an acknowledgment within **48 hours** of your report
- I will investigate and provide a status update within **7 days**
- If the vulnerability is confirmed:
  - A fix will be released in the next update
  - You will be credited in the release notes (if you wish)
- If the vulnerability is declined, I will explain the reason

### Responsible Disclosure

Please do not publicly disclose the vulnerability until a fix has been released.
User safety is the priority.
